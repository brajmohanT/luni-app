# Luni

> **Human-authored document.** Only humans may write or edit this file. Agents may read it but must not change it.

Luni is a mobile AI companion. Users will start with text chat. The team plans voice input and output for a future release.

The existing backend uses Express, Node.js, managed PostgreSQL, and supporting libraries. It handles the service behind the mobile app.

We will build the mobile client with React Native for Android and iOS.
